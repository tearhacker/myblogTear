“一念”APP UI 设计文档
 
一、项目概述
 
1.1 项目名称
 
一念（Nian Nian）—— 专属思念记录APP
 
1.2 核心定位
 
为用户提供一个私密、仪式化的情感表达工具，通过每日“念你”签到，记录对特定对象的思念与陪伴，将抽象的情感转化为可感知的时间刻度与专属回忆。
 
1.3 目标用户
 
- 核心用户：有明确情感寄托对象（如恋人、暗恋对象），希望通过持续行动表达心意的年轻人。
- 情感需求：渴望专属感、仪式感与安全感，希望让对方感受到自己的坚持与真诚。
 
 
 
二、设计原则
 
1. 真诚至上：UI 服务于情感表达，避免过度炫技，让用户的心意成为核心。
2. 专属感：所有视觉与交互都围绕“唯一的TA”展开，强化“只属于你”的体验。
3. 仪式感：通过时间刻度、成就解锁、动画反馈，让每一次“念你”都有仪式感。
4. 温暖柔和：整体风格偏向治愈、细腻，避免尖锐、冰冷的视觉元素。
 
 
 
三、视觉设计规范
 
3.1 色彩系统
 
类型 色值 应用场景 
主色 #FF6B9D（柔粉） 品牌色，用于主按钮、标题、强调元素 
辅助色1 #F8B1C8（豆沙粉） 卡片背景、进度条填充 
辅助色2 #FFF0F5（米白粉） 页面背景、次要按钮背景 
文字主色 #333333（深灰） 正文、重要信息 
文字次色 #999999（浅灰） 辅助说明、次要信息 
强调色 #FF477E（亮粉） 数字、成就徽章、动画元素 
 
3.2 字体系统
 
层级 字体 字号 字重 应用场景 
大标题 思源宋体 32sp 600 页面主标题（如“致 欧阳颖”） 
数字强调 思源黑体 64sp 700 核心数字（如“1天”） 
正文 思源黑体 16sp 400 常规文本、说明文字 
辅助文本 思源黑体 14sp 300 次要说明、时间戳 
 
3.3 图标与图形
 
- 核心图标：爱心（❤️），采用圆润饱满的设计，避免尖锐棱角。
- 辅助图形：环形进度条、线性进度条、时光轴节点，均采用圆角处理。
- 质感：主按钮采用轻微渐变与阴影，模拟“玻璃质感”，提升可点击感与珍视感。
 
 
 
四、核心页面设计
 
4.1 首页（念你页）
 
核心目标：让用户一键完成“今日念你”，并直观感受到自己的坚持。
 
布局结构
 
1. 顶部区域
- 左侧：“致 欧阳颖”（大标题，思源宋体 32sp）
- 副标题：“一念情深，念念不忘”（辅助文本，思源黑体 16sp，#999999）
2. 核心交互区（视觉中心）
- 圆形玻璃质感按钮（直径 300dp）
- 内部元素：
- 顶部：红色爱心图标（❤️）
- 中间：“已念你”（正文，思源黑体 20sp）
- 核心数字：“1”（数字强调，思源黑体 64sp，#FF477E）
- 底部：“天”（辅助文本，思源黑体 16sp）
3. 情感文案区
- 主文案：“有些话藏在心里，却用签到记录每一天的思念。”（正文，居中）
- 次文案：“今日已念，明日继续~”（辅助文本，居中，#999999）
4. 数据展示区
- 左侧：“累计念你 1 天”（线性进度条，填充色 #F8B1C8）
- 右侧：“连续念你 1 天”（线性进度条，填充色 #FF477E）
5. 底部专属文案
- “从初中到现在，一直都在…”（可编辑文本，思源黑体 14sp，#999999）
 
交互逻辑
 
- 点击核心按钮：
1. 播放爱心飘散动画（10-15 个粉色爱心从中心向四周飘散）。
2. 播放轻柔心跳声（可选音效）。
3. 数字 +1，进度条同步更新。
4. 弹出“今日思念已送达”的轻量提示。
 
 
 
4.2 时光轴页（回忆页）
 
核心目标：沉淀用户的思念记录，成为专属回忆册。
 
布局结构
 
1. 顶部导航
- 返回按钮 + 标题“时光轴” + 筛选按钮（按时间/关键词）
2. 时间线主体
- 垂直时间轴，按日期倒序排列。
- 每个节点包含：
- 日期戳（如“2026-03-07 21:56”）
- 当日“念你”文案（用户可编辑）
- 可选附件：照片、语音、位置信息
- 天气/心情标签（如“🌧️ 有点想你”）
3. 顶部统计卡片
- 环形进度条：“累计念你 1/365 天”
- 成就徽章：“连续打卡 1 天”（满30天解锁“初心不改”徽章）
 
交互逻辑
 
- 点击节点：展开详情，可编辑文案、添加附件。
- 下拉刷新：加载更早的记录。
- 长按节点：可分享为图片（生成专属思念卡片）。
 
 
 
4.3 专属故事页
 
核心目标：强化“专属感”，记录从初识到现在的完整故事。
 
布局结构
 
1. 封面区
- 背景：用户自定义照片（如初中合照）
- 标题：“从初中到现在，一直都在…”（可编辑）
- 副标题：“我们的故事，未完待续”
2. 故事章节
- 按时间线划分章节（如“初识”“心动”“陪伴”）。
- 每个章节包含：
- 章节标题
- 关键回忆描述
- 关联照片/语音
3. 重要日期提醒
- 相识纪念日、对方生日、情人节等。
- 临近日期时，首页弹出提醒：“距离TA的生日还有7天，准备一份特别的念你吧~”
 
 
 
五、交互与动效规范
 
1. 核心按钮动效
- 未点击：轻微呼吸动画（缩放 ±5%）。
- 点击：缩放至 95% → 回弹至 105% → 恢复 100%，伴随爱心飘散。
2. 进度条动效
- 数字更新时，进度条平滑填充，伴随数字滚动动画。
- 满成就时（如30天），播放彩带飘落动画。
3. 页面切换
- 采用淡入淡出或水平滑动过渡，避免生硬跳转。
- 时光轴页滚动时，时间节点随滚动渐显。
 
 
 
六、迭代 roadmap
 
阶段一（MVP）
 
- 完成首页核心交互（签到、数字更新）。
- 实现基础时光轴（纯文本记录）。
- 优化视觉层次与色彩。
 
阶段二（情感升级）
 
- 增加照片/语音附件功能。
- 解锁30天、100天成就动画与徽章。
- 生成专属思念卡片（可分享）。
 
阶段三（专属深化）
 
- 完成专属故事页。
- 增加重要日期提醒。
- 支持自定义背景、音效、字体。
